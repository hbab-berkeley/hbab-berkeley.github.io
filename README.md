# HBAB website

Healthcare Business Association at Berkeley. A static site: one `index.html` plus an `img/` folder. No build step.

## Hosting (GitHub Pages)
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.

## Common edits
- **Board members:** in `index.html`, search for `const TEAM` — one line per person (photo, name, role, scheduling link).
- **Photos:** team headshots in `img/team/`, page backgrounds in `img/groups/`, gallery in `img/gallery/`.
- **Links:** the application, coffee chat, DeCal, Instagram, and LinkedIn URLs are plain links in `index.html`.
